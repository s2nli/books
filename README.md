# CODEXSTUDYS BOOKS
Open index.html (or deploy folder on Vercel/Netlify). Data: data/books.js (3,563 local books).
Live sources (browser APIs, in the same library): Pinnacle, Gutenberg, Open Library, Google Books, Standard Ebooks, Crossref, arXiv, Semantic Scholar, PubMed Central, LibriVox, MangaDex, Jikan.
If an API is blocked by CORS, deploy proxy-worker.js (Cloudflare Worker) and set PROXY in index.html.
Not included on purpose: shadow libraries (Anna's Archive, Z-Library, LibGen, IPFS indexers), unofficial scrapers (NovelUpdates, Royal Road, AO3), ISBNdb (paid key), Goodreads (no API).
